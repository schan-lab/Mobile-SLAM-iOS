Mobile SLAM

LiDAR を iPhone に有線でつなぎ、その場で 3D マップ作成と自己位置推定を行うアプリです。

はじめに

  1. iPhone に有線 LAN アダプターを挿し、設定 → Ethernet → アダプター名 → IP を構成 → 手動 で、IP アドレスを Mid-360 に設定した送信先 IP に、サブネットマスクを Mid-360 と同じサブネットのものにします（工場出荷時は 192.168.1.50 / 255.255.255.0）。Mid-360 の IP や送信先は、アプリの 設定 → Mid-360 から変更できます。
  2. アプリを起動し、「ローカルネットワーク」へのアクセスを許可します。
  3. Livox Mid-360 をつないで電源を入れ、画面上部の Ethernet・Mid-360・IMU が緑になれば受信できています。
  4. 「マップ作成 開始」を押し、最初の数秒は静止してから、ゆっくり歩きます。

実機がない場合は、設定 → 「実機なしで試す」をオンにすると、疑似データで操作を試せます。

よくある質問

LiDAR が緑にならない
IP アドレスの設定と、設定 → プライバシーとセキュリティ → ローカルネットワーク で Mobile SLAM が許可されているかを確認してください。

保存したマップはどこにありますか
ファイル App の「このiPhone内 › Mobile SLAM」にあります。アプリ内の 3D 表示画面から共有もできます。

Mobile SLAM (English)

Build 3D maps and localize on the spot with a LiDAR connected to your iPhone by wired Ethernet.

Getting started

  1. Plug a wired Ethernet adapter into your iPhone. In Settings → Ethernet → (adapter) → Configure IP → Manual, set the IP address to the Mid-360's destination (host) IP and the subnet mask to match the Mid-360's subnet (factory default: 192.168.1.50 / 255.255.255.0). You can change the Mid-360's IP and destination in the app under Settings → Mid-360.
  2. Open the app and allow Local Network access.
  3. Connect and power the Livox Mid-360. When Ethernet, Mid-360 and IMU turn green at the top, data is coming in.
  4. Tap “Start Mapping”, hold still for a few seconds, then walk slowly.

No hardware? Turn on Settings → “Try Without Hardware” to try the app with simulated data.
